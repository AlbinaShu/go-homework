# Go Homework 4

Домашнее задание по теме объектно-ориентированного программирования в Go.

## Ledger

В сервисе Ledger добавлены:

- интерфейс `Validatable`;
- метод `Validate()` для `Transaction`;
- метод `Validate()` для `Budget`;
- валидация перед добавлением транзакций и бюджетов;
- функция `CheckValid`, работающая с разными типами через интерфейс;
- сохранена проверка лимита бюджета из предыдущего задания;
- загрузка бюджетов из `budgets.json`.

## Требования

- Go 1.22+

## Запуск

Из папки `hw4` перейти в Ledger:

```bash
cd ledger
```

Запустить программу:

```bash
go run .
```

Файл `budgets.json` должен находиться в папке `ledger` рядом с `main.go`.
