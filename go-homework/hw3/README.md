# Go Homework 3

Домашнее задание по дисциплине "Язык Go".

## Ledger

В сервисе Ledger реализована работа с транзакциями и бюджетами по категориям.

Реализовано:

- хранение транзакций;
- хранение бюджетов по категориям;
- добавление и обновление бюджетов;
- проверка бюджета при добавлении транзакции;
- загрузка бюджетов из JSON-файла;
- обработка ошибок.

## Требования

- Go версии 1.22+

## Запуск

Перейти в папку Ledger:

```bash
cd ledger
```

Запустить программу:

```bash
go run .
```

Бюджеты загружаются из файла `budgets.json`.

Пример:

```json
[
  {
    "Category": "Food",
    "Limit": 5000
  },
  {
    "Category": "Transport",
    "Limit": 3000
  }
]
```

При запуске программа добавляет несколько тестовых транзакций.

Если сумма расходов по категории превышает установленный бюджет, транзакция отклоняется и не сохраняется.
